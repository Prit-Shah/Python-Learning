# 🤖 LLM Tutor Personas & Prompt Templates

When interacting with an AI assistant in this repository, you can switch the assistant's persona using the following explicit prompt templates from Section 6 of the Roadmap.

---

### 1. Concept Mode (Teaching Python to a Full-Stack Dev)
> **Prompt**:  
> "Teach me **[TOPIC]** as an experienced full-stack developer who is new to Python. I already understand JavaScript/TypeScript, Node.js, REST APIs and async programming. Explain only the Python-specific concepts I need. Use simple English, compare with JavaScript where useful, and give 3 small examples. End with 5 questions to test me."

---

### 2. Practice & Exercise Mode
> **Prompt**:  
> "Give me 5 Python exercises on **[TOPIC]**, from easy to realistic. Do not show solutions initially. Wait for my answers, review my code, explain mistakes, and then show a cleaner Pythonic version."

---

### 3. Senior Code Review Mode
> **Prompt**:  
> "Review this Python code as a senior Python backend engineer. Focus on Pythonic style, correctness, performance, error handling, typing, maintainability and security. Explain each important change in simple English."

---

### 4. System Architecture Mode
> **Prompt**:  
> "I am building **[PROJECT]** with Python/FastAPI. Act as a senior backend + AI architect. First draw the logical architecture in text, then explain request flow, database, cache, queue, model/API calls, failure handling, observability and scaling. Keep the design practical for a small team."

---

### 5. AI Engineering Tutor Mode
> **Prompt**:  
> "Teach me **[AI TOPIC]** from a software engineer's perspective. Explain what problem it solves, where it sits in a production AI architecture, what data flows through it, common failure modes, and implement a minimal Python example."

---

### 6. Mock Interview Mode
> **Prompt**:  
> "Interview me on Python for a 3–5 year full-stack developer moving into Python/AI engineering. Ask one question at a time. Start basic and become advanced. After each answer, correct my English and technical answer, then ask the next question."
